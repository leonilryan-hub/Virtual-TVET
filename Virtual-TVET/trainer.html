Let learners scan this code

Learners open their phone camera and scan. Then they log in with their Trainee ID and PIN, and the campus opens for 30 days. The code changes every 30 seconds, so a photo of it soon stops working.

NFC tag (sticker or card)

Keep an NFC sticker or card with you. A learner taps it with their phone, logs in, and the campus opens. This works on Android phones and on iPhone XS or newer. Keep the tag with you: anyone who taps it can activate.

No "Write" button support?

Writing from this page works in Chrome on Android. On other phones, install the free app NFC Tools, choose Write → Add a record → URL, paste the link above, and write it to the tag.

Change tag code makes all old tags stop working (use it if a tag is lost). Then write the new link to your tag again.

✨ 5S housekeeping check

Rate each S from 1 (poor) to 5 (excellent). Sort: only needed items in the area · Set in order: a place for everything, labelled · Shine: clean and inspected · Standardize: rules and schedules posted and followed · Sustain: everyone keeps the habit.
