🔐 Protect Files (encrypt CBLMs for GitHub)

Virtual TVET Campus · Access Lock

What this does

Makes a locked copy (.enc) of every CBLM in your Basic, Common, Core (and LMS, if you have one) folders. Only these locked copies go to GitHub. A learner's phone can open a locked copy only while their campus access is active, because the key comes from your Google Sheet.

Your original files are not changed. Everything runs on this PC; nothing is sent anywhere.

Step 1 · Paste the ContentKey

Open your Google Sheet → Settings tab → copy the value beside ContentKey.

Step 2 · Choose your "EIM NC III CBLM" folder

Pick the folder that holds Basic, Common, Core and Virtual-TVET. The locked copies are saved in a new folder inside it named GitHub-Upload (protected).

This browser cannot save into a folder. Use Google Chrome or Microsoft Edge on a PC. Or pick files below; each locked copy will download separately.

Step 3 · Upload to GitHub

  1. Open GitHub-Upload (protected). You will see Basic, Common and Core folders with .enc files.
  2. In your GitHub repository click Add file → Upload files, drag in those three folders, and click Commit changes.
  3. In Virtual-TVET/config.js set protectedFiles: true and upload config.js.
  4. Remove the unprotected .docx files from GitHub (see README, part D).

Each time you add or revise a CBLM, run this tool again and upload the new .enc file.
