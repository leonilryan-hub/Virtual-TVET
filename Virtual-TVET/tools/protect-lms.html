🔐 Protect LMS Simulators (encrypt for GitHub)

Virtual TVET Campus · Access Lock

What this does

Turns each interactive LMS simulator folder into locked pieces (one .enc file per page, picture and video, with scrambled names). Only these pieces go to GitHub. A learner can open a simulator only inside the campus, after entering their PIN, while their access is active, on their own device. The pieces are unlocked in the phone's memory only; nothing readable is saved on the phone.

Your original folders are not changed. Everything runs on this PC; nothing is sent anywhere.

Step 1 · Put your simulators in an "LMS" folder

  1. Inside your EIM NC III CBLM folder, make a new folder named LMS.
  2. Copy each simulator folder into it (unzip the .zip ones first). Each folder must have its index.html inside, for example LMS\MotorControl_LMS\index.html.

Step 2 · Paste the ContentKey

Google Sheet → Settings tab → copy the value beside ContentKey (the same key you used for the CBLMs).

Step 3 · Choose your "EIM NC III CBLM" folder

This browser cannot open folders. Use Google Chrome or Microsoft Edge on a PC.

Check the name and unit of each simulator, then click Protect. The Short name becomes part of the web link, so keep it the same when you protect a revised version.

Step 4 · Upload to GitHub

  1. Open GitHub-Upload (protected). You will see an LMS folder: one folder of .enc pieces per simulator, plus lms-list.js.
  2. In your GitHub repository click Add file → Upload files, drag in the whole LMS folder, and click Commit changes. GitHub takes at most 100 files per upload: if a simulator has more, upload its folder in two parts (open LMS on GitHub, then upload the rest into the same simulator folder).
  3. Never upload the plain simulator folders or their .zip files.

When you revise a simulator, run this tool again and upload its folder and lms-list.js again. If you change the ContentKey, protect and upload everything again.
